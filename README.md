## Weather App

A simple web application that displays real-time weather information for any city searched by the user. Built to practice API integration, asynchronous JavaScript, and dynamic DOM manipulation.

**Features:**
- Search weather by city name
- Displays temperature, "feels like" temperature, weather condition, humidity, and wind speed
- Error handling for invalid or misspelled city names
- Responsive, clean UI

**Tech Stack:** HTML, CSS, JavaScript, OpenWeatherMap API

**How to run:**
1. Clone this repository
2. Add your own OpenWeatherMap API key in `config.js`
3. Open `index.html` in your browser
